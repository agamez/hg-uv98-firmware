## Structure notes

- States = screen IDs; ui_state_set = the screen-switch function
  (0x08010530; band ring snapshot + state write, REA-validated).
- RF states 'g'(RX)/'h'/'i'/'j'(beacon windows) are entered from the
  protocol handlers, not the menu tree.
- Second-level screens 0x33-0x8D are reached only through the even
  hub items 0x00/0x02/0x04/0x06/0x08/0x0A/0x0C.
- Session 31, REA/capstone; addresses = label space (file+0x08000000).
