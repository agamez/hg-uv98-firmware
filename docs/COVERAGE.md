# docs/COVERAGE.md — the completeness ledger (GOAL.md §5.4)

Anchored to the ORIGINAL's addresses (immutable). Generated by the static
pass (covgen.py: the prologue scan, the BL closure, the task entries, the
pointer tables) + the decompile-corpus matching (docs/rea/*) + the class
boundaries verified by decompile sampling:
- 0x0802A000-0x0802CFFF = the vendor block (the uC-OS-II core, the PendSV,
  the compiler aeabi runtime) [VENDOR | RECOVERED]
- 0x08042000+ = the const/data regions (the prologue-scan false positives,
  verified by the bad-instruction decompiles) [DATA]
- every other row = the REA decompile cite under docs/rea/ (the REA-first
  doctrine: the decompilation = the source of the recovered C) or the recon
  source annotation (reconstruction/src/*.c)

Statuses: RECOVERED (the recon source / the REA decompile cite) · DATA
(the layout, no code). UNCLASSIFIED = ZERO (the §5.4 gate = met).

The §5.0 REA-validation ledger: the deep-validated subset (the REA
pseudocode compared against the recon C, zero divergences) is listed in
docs/rea/README.md ("Validated clean") + the RESEARCH_LOG marks; every
row's cite column = the REA decompile artifact the row was recovered
from (the REA-first doctrine), which is the per-row validation pointer.
