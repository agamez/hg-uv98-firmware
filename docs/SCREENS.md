## Pump clusters

- 0x0800A2xx-0x0800Bxxx: the main/VFO screen family (the largest
  group; list IDs 1/2/3/7/8/9/15/25/26/59)
- 0x08011Cxx-0x08013xx: the menu screens (list IDs 6/9/10/30/40/49/51)
- 0x08014Bxx-0x08014Dxx: list IDs 4/5
- 0x0800F1F0/0x0800F26C: list IDs 6/59 (the main-screen pumps)
- List ID 0xD3 (2 sites): a special list

Per-session 18/32: each pump reads the key ID byte, indexes its
8-byte-stride key-action table, moves the selection via
ui_list_select, and issues the 20-byte redraw block; activation
goes through the binary-search dispatcher to ui_state_set.
Session 32; addresses = label space (file+0x08000000).
